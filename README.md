# 💫 About Me:
**Software Developer at BARS in Rome, a DocuSign partner.** I connect DocuSign to enterprise systems (SAP, SharePoint, Microsoft Entra ID and HR platforms) with Java/Spring Boot, Node.js and TypeScript: Maestro Data IO extension apps, eSignature API automation, OAuth 2.0 and SOAP/REST integrations. Client work stays private.

On my own I build RAG systems and AI agents. Before BARS I was a VR and haptics researcher at Università Roma Tre.
